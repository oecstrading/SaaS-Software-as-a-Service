# OECS Software Applications

Public catalogue: https://oecstrading.github.io/SaaS-Software-as-a-Service/#catalogue

Applications-only catalogue with search, sector filters and direct external launch links. This static site uses index.html, styles.css, app.js and catalog-data.js. catalog.json contains only public application descriptions and destinations. Entries without a public destination are omitted.

For data edits, keep catalog.json and catalog-data.js synchronized and increment asset versions in index.html when publishing.
