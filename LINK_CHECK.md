# SaaS portfolio link audit — 15 November 2026

Only this GitHub repository was modified. No Lovable or Manus apps, authentication settings, or data were changed.

All 43 original listing destinations were checked. The first 27 company-site routes returned the same homepage; 15 /apps paths resolved outside the project and returned 404. Direct application destinations were recovered from the existing repository catalogue and confirmed by HTTP requests. Browser entry-page checks additionally identified blank/loading applications and sign-in requirements. HTTP 200 alone does not establish working features or anonymous access.

## Remaining limitations

PMIS, Dominica DOMCREP and Grenada UBEC did not render a usable entry page during browser checks (fetch failures/loading). Their launch links are withheld. Seven other exact public demos were not found: eLand, TV/Radio, Vieux Fort, Haiti Industrial, GCF/CDB Concept Note, Rivet & Roan and CaribCarbon. These listings remain in the portfolio with Request demo controls. No different product has been substituted.

Easy Sales and Close Command require sign-in; AML/CFT requires a local password. Public marketing pages may also require sign-in for operational features. The catalogue itself remains public and read-only. The Micro-Lending Matrix shares the verified Caribbean Finance Hub endpoint, and the financial-statement listing shares the verified IFRS/GAAP reporting endpoint.

## Changes

- Replaced misleading homepage routes and broken project-root paths.
- Open apps directly in new tabs to avoid iframe restrictions and embedded authentication problems.
- Restore catalogue anchor, Browse, Inquire, contact and request-demo controls.
- Inquiry form prepares an email draft; it does not claim delivery.
- Synchronise the two catalogue data files and repair all 15 legacy app aliases.
- Keep all 43 entries, design, profile, inquiry selections and GitHub-only administration.
